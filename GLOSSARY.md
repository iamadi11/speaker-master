# Glossary

| Term | Meaning |
|---|---|
| **Auto** | One-run optimize path; user picks Measure or Narrow |
| **Measure** | Mic-based correction for the connected speaker |
| **Narrow** | Preset / narrowed path without mic; persists per speaker until Retry |
| **Custom** | Pro EQ console with progressive disclosure |
| **Retry** | Explicit user action that clears Narrow/Measure persistence for re-run |
| **Process tap** | Core Audio system/process audio capture used for system-wide EQ |
| **Per-speaker profile** | Stored EQ state keyed to Core Audio output UID / device identity |
| **Safety sheet** | Written boost/limiter caps; required before shipping DSP changes |
| **Personal install** | Local ad-hoc / free-signing install on the owner’s Mac only |
