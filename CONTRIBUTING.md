# Contributing (agents & humans)

## For agents

1. Read `AGENTS.md` and `docs/agent-workflow.md` first.
2. Use project skills under `.agents/skills/`.
3. Branch from `main`: `cursor/<short-description>-1c86`.
4. Keep slices small. Prefer `/grill-me` before ambiguous product work.
5. Verify with `swift test`. Merge only when green. No force-push to `main`.
6. App install on the owner’s Mac: `/autonomous-gap-fix` gates or `Scripts/install-personal.sh` after verify.

## For humans

- Issues: GitHub Issues on this private repo.
- PRs required conceptually even before branch protection UI is enabled.
- Product questions: check `docs/product-brief.md` before proposing features.
